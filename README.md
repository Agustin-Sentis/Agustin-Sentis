## 🚀 Proyectos destacados

### 🐾 VetCare — Gestión de clínicas veterinarias (Presentacion del proyecto final de la carrera).
Sistema full-stack en producción para administrar una clínica veterinaria.

- **Backend:** ASP.NET Core (.NET 10) con Clean Architecture, EF Core y SQL Server (Azure SQL), desplegado en Azure Web Apps
- **Frontend:** React + Vite desplegado en Azure Static Web Apps
- **CI/CD:** GitHub Actions con despliegue automático
- **Seguridad:** autenticación con JWT, auditoría de inyección SQL y manejo de sesión con cookies httpOnly
